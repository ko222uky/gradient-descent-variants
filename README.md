# Overview

Implementations of gradient descent variants for CSE 620 Combinatorial Optimization and Modern Heuristics course with Dr. Olfa Nasraoui at the University of Louisville.

This code was made public for the purposes of submission.

# How to run it

Requires `uv`:

* https://docs.astral.sh/uv/

To run, use:

```
uv run main.py
```

Edit the `main.py` to configure the methods and parameters used.
